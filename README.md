# Superstore Sales Analysis

## Project Overview
This project analyzes sales data from a fictional Superstore to uncover insights about sales performance, profitability, regional differences, and the impact of discounts.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analyses
- Sales and Profit by Region
- Sales and Profit by Category
- Monthly Sales Trend
- Top Loss-Making Products
- Sales by Customer Segment
- Relationship between Discount and Profit
- Top Sub-Categories by Sales and Profit

## Key Insights
- The West region has the highest sales.
- Technology is the most profitable category.
- High discounts (especially above 30%) often lead to losses.
- Some products generate significant losses and need review.
- The Consumer segment contributes the most to total sales.

## How to Run
1. Clone this repository
2. Open the notebook in Jupyter
3. Make sure the superstore.csv file is in the same folder
4. Run all cells
